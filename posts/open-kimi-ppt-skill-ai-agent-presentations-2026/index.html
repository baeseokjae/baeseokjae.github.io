What Is Open-Kimi-PPT-Skill and Why Is It Exploding in Popularity?#

Open-Kimi-PPT-Skill is an open-source, MIT-licensed skill file that enables AI coding agents like Claude Code, Codex, Cursor, and WorkBuddy to generate fully editable presentations by reverse-engineering Kimi Slides’ proprietary PPTD format. Within 24 hours of its August 5, 2026 release, the project amassed 615 GitHub stars and 174 forks, making it one of the fastest-growing AI presentation tools on the market. It produces both PPTD (editable project files) and PPTX (ready-to-share exports) by default, with zero runtime dependencies.

What Exactly Is Open-Kimi-PPT-Skill?#

Open-Kimi-PPT-Skill is an unofficial, community-built skill file that reverse-engineers the Kimi Slides presentation format — a YAML-based intermediate DSL called PPTD — and exposes it as a SKILL.md file compatible with any AI coding agent that supports the skill-file protocol. Created by developer Binaryify and published on GitHub, the project bridges the gap between AI coding agents and traditional presentation software.

The project ships as both a GitHub repository and an npm package (open-kimi-ppt-skills v1.0.0). It supports five core workflows:

  • Create — Generate a new presentation from a text prompt
  • Edit — Modify an existing PPTD project with natural language instructions
  • Replicate — Clone and restyle an existing presentation
  • Read — Parse and understand the content of a PPTD file
  • Export — Convert PPTD to PPTX for distribution

The skill is agent-agnostic by design. It works with Claude Code, Codex, Cursor, WorkBuddy, and any other agent that supports the SKILL.md protocol. This cross-platform compatibility is a major reason for its rapid adoption.

How Does the PPTD Format Work?#

The PPTD format is the core innovation behind Open-Kimi-PPT-Skill. It is a YAML-based intermediate DSL that abstracts the complexity of OOXML (the underlying format of PPTX files) into a human-readable, AI-friendly structure.

PPTD Structure#

A typical PPTD file defines presentations as a hierarchy of slides, each containing elements like text boxes, images, shapes, and charts. Here is a simplified example of what the YAML structure looks like:

presentation:
  title: "AI Market Trends 2026"
  slides:
    - type: title
      title: "AI Market Trends 2026"
      subtitle: "A Comprehensive Analysis"
    - type: content
      title: "Market Growth"
      bullets:
        - "Global AI market reached $196B in 2025"
        - "Projected CAGR of 37.3% through 2030"
        - "Enterprise adoption at 72% in 2026"
    - type: comparison
      title: "AI vs Traditional Automation"
      left_column: ["Speed", "Cost", "Accuracy"]
      right_column: ["10x faster", "40% lower", "95% vs 82%"]

This YAML structure is far easier for AI agents to generate correctly than raw OOXML. The PPTD format handles:

  • Font embedding — Auto-embeds fonts so presentations render correctly on any system
  • Slide transitions — Applies fade transitions by default
  • Layout templates — Supports title, content, comparison, data, and image slide types
  • Theme management — Color schemes, typography, and spacing are defined declaratively

Why PPTD Matters#

The PPTD format solves a fundamental problem in AI-generated presentations: AI models are good at generating structured text but terrible at producing valid OOXML. By creating an intermediate DSL, Open-Kimi-PPT-Skill makes AI-generated presentations both reliable and editable. Users can open a PPTD file in the included local browser-based editor, make manual adjustments, and then export to PPTX.

Architecture#

The architecture follows a simple pipeline:

  1. User prompt → AI coding agent receives a natural language request (e.g., “Create a 10-slide pitch deck for a SaaS startup”)
  2. Skill activation → The agent loads the SKILL.md file, which provides instructions and templates for PPTD generation
  3. PPTD generation → The agent outputs a YAML-based PPTD file representing the presentation structure
  4. Optional editing → The user can open the PPTD in the local browser editor for manual adjustments
  5. PPTX export → The PPTD file is converted to a standard PPTX file ready for PowerPoint, Google Slides, or Keynote

This pipeline is remarkably efficient. A 10-slide presentation can go from prompt to PPTX in under 60 seconds, depending on the complexity of the content and the AI agent used.

How Do You Install and Set Up Open-Kimi-PPT-Skill?#

Installation is straightforward and takes less than five minutes.

Prerequisites#

  • An AI coding agent that supports SKILL.md files (Claude Code, Codex, Cursor, WorkBuddy, etc.)
  • Node.js 18+ or Python 3.8+
  • npm or pip for package installation

Installation via npm#

npm install -g open-kimi-ppt-skills

Installation via GitHub#

git clone https://github.com/Binaryify/open-kimi-ppt-skill.git
cd open-kimi-ppt-skill
npm install

Agent Configuration#

For Claude Code, add the skill to your project’s SKILL.md file or reference it in your Claude Code configuration:

claude code --skill open-kimi-ppt-skill

For Codex, place the SKILL.md file in your project root or reference it in your Codex configuration:

codex --skill ./open-kimi-ppt-skill/SKILL.md

For Cursor, add the skill file to your .cursor/rules/ directory.

The setup is intentionally minimal. The project’s zero-dependency philosophy means you do not need to install any additional libraries or frameworks.

Competitive Analysis#

ppt-agent-skill (Akxan) is the most feature-rich competitor with 26 design styles and 18 chart types. It produces presentation-quality decks benchmarked against design systems from Linear, Anthropic, Stripe, Apple, and the New York Times. Its presentations are interactive and visually impressive, but they are not native PPTX files. This makes them ideal for web-based presentations but less suitable for corporate environments that require PowerPoint compatibility.

Open-Kimi-PPT-Skill’s unique advantage is its dual-delivery model (PPTD + PPTX), its agent-agnostic design, and its reverse-engineered access to the Kimi Slides format. No other project offers all three.

What Is the Reverse-Engineering Story Behind Kimi Slides?#

The most intriguing aspect of Open-Kimi-PPT-Skill is its origin story. The project is an unofficial reverse-engineering of Kimi Slides, a presentation generation feature within Kimi — Moonshot AI’s Chinese-language AI assistant.

How It Was Done#

The developer, Binaryify, analyzed the network requests and output format of Kimi Slides to understand how the platform generates presentations. By examining the PPTD format that Kimi Slides uses internally, Binaryify was able to:

  1. Decode the YAML schema — Identify the structure and fields of the PPTD format
  2. Map PPTD to OOXML — Understand how each YAML element translates to PPTX XML
  3. Build a converter — Create a tool that transforms PPTD files into valid PPTX output
  4. Package as a skill — Wrap the entire system in a SKILL.md file for AI agent compatibility

What This Means for the Ecosystem#

The reverse-engineering of Kimi Slides’ PPTD format has significant implications:

  • Democratization — A proprietary AI presentation format is now available to anyone, regardless of whether they use Kimi
  • Standardization potential — PPTD could become a de facto standard for AI-generated presentations, much like Markdown became the standard for AI-generated text
  • Ecosystem growth — Other developers can now build tools that work with the PPTD format, creating a rich ecosystem of editors, converters, and templates
  • Competitive pressure — Moonshot AI may need to officially support or open-source the PPTD format to maintain relevance

It is important to note that Open-Kimi-PPT-Skill is not affiliated with Moonshot AI or Kimi. It is a community project that operates in a legal gray area — reverse-engineering APIs and file formats is generally permitted under fair use for interoperability purposes, but users should be aware of the unofficial nature of the project.

What Are the Best Use Cases and Practices?#

Open-Kimi-PPT-Skill shines in several specific scenarios.

1. Rapid Pitch Deck Creation Startups and entrepreneurs can generate investor-ready pitch decks in minutes. A 10-slide deck that would take a designer 4-6 hours to build can be created in under 60 seconds with a well-crafted prompt.

2. Sales Presentation Automation Sales teams can generate customized presentations for each prospect. By varying the prompt with prospect-specific data, each presentation feels tailored without requiring manual redesign.

  • Iterate in PPTD — Make structural changes in the PPTD format, not in PowerPoint
  • Use the local editor — The browser-based PPTD editor is excellent for fine-tuning before export
  • Version control your PPTD files — Since PPTD is YAML, it works naturally with git
  • Combine with other skills — Use research skills to gather data, then feed it into the presentation skill

What Are the Current Limitations and Considerations?#

Despite its impressive capabilities, Open-Kimi-PPT-Skill has several limitations that users should understand.

Technical Limitations#

  • Design sophistication — The generated presentations use basic templates, not the 26 design styles offered by ppt-agent-skill
  • Chart support — Only basic tables are supported; advanced charts and data visualizations require manual creation
  • Animation control — Only fade transitions are supported; custom animations are not available
  • Image generation — The skill does not generate images; you must provide your own or use a separate image generation tool
  • Very early stage — The project is only 1 day old; bugs and edge cases are expected

Legal and Ethical Considerations#

  • Unofficial project — Open-Kimi-PPT-Skill is not affiliated with Moonshot AI or Kimi
  • Reverse-engineering risks — Moonshot AI could change their API or format, breaking compatibility
  • No warranty — As with all MIT-licensed software, there is no guarantee of continued functionality
  • Attribution — Users should be transparent about using AI-generated presentations when appropriate

Ecosystem Maturity#

The PPTD format is currently only supported by Open-Kimi-PPT-Skill. While the format has potential as a standard, it lacks the ecosystem of tools, templates, and community resources that more established formats enjoy. Adoption will depend on whether other projects embrace the PPTD format or create competing standards.

What Does the Future Hold for AI Agent-Driven Presentations?#

The explosive growth of Open-Kimi-PPT-Skill — 615 stars in 24 hours — signals a massive unmet demand for AI-powered presentation generation. Several trends are likely to shape the future of this space.

The Rise of Intermediate DSLs#

PPTD represents a broader trend: AI agents work best with intermediate domain-specific languages that bridge natural language and complex output formats. Just as Markdown became the standard for AI-generated text, intermediate DSLs like PPTD may become the standard for AI-generated structured documents.

Agent-Agnostic Skills#

The SKILL.md protocol is emerging as a universal interface for AI coding agents. Open-Kimi-PPT-Skill’s compatibility with five different agents demonstrates the power of this approach. Future presentation tools will likely follow the same pattern, prioritizing cross-platform compatibility over platform lock-in.

From Generation to Collaboration#

The current generation of AI presentation tools focuses on one-shot generation. The next evolution will likely involve collaborative workflows where humans and AI agents iterate on presentations together, with the AI handling structure and formatting while humans focus on strategy and messaging.

Enterprise Adoption#

As tools like Open-Kimi-PPT-Skill mature, enterprise adoption will accelerate. The ability to generate consistent, on-brand presentations at scale is a compelling value proposition for marketing, sales, and internal communications teams.

Frequently Asked Questions#

Is Open-Kimi-PPT-Skill free to use?#

Yes, Open-Kimi-PPT-Skill is completely free and open source under the MIT License. There are no usage restrictions, subscription fees, or hidden costs. You can use it for personal, commercial, or educational purposes without attribution.

Does Open-Kimi-PPT-Skill work with PowerPoint?#

Yes. The skill generates PPTX files that are fully compatible with Microsoft PowerPoint, Google Slides, Apple Keynote, and LibreOffice Impress. The PPTD format can also be edited in the included browser-based editor before export.

What AI agents are compatible with Open-Kimi-PPT-Skill?#

The skill works with any AI coding agent that supports the SKILL.md protocol, including Claude Code, Codex (by OpenAI), Cursor, WorkBuddy, and Windsurf. This agent-agnostic design is a key differentiator from competing tools that are locked to a single platform.

How long does it take to generate a presentation?#

A typical 10-slide presentation takes 30-60 seconds from prompt to PPTX output, depending on content complexity and the AI agent used. The actual generation time is dominated by the AI agent’s response time rather than the conversion process.

Can I edit a presentation after it is generated?#

Absolutely. The dual-delivery model means you get both a PPTD project file (editable in the browser-based local editor) and a PPTX file (editable in PowerPoint or Google Slides). You can make structural changes in PPTD, fine-tune in the editor, and then re-export to PPTX.
