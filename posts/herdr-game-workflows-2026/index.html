Herdr Game is a free, browser-based interactive game that teaches you how to use Herdr — the rapidly growing terminal workspace manager for AI coding agents — through 34 hands-on lessons across 8 chapters. Released on August 2, 2026 by John Lindquist, the game provides an isolated Herdr session via Vercel Sandbox, validates your actions against live Herdr state, and requires no API key or account to start playing.

What Is Herdr? — The Runtime for AI Coding Agents#

Herdr is an open-source terminal workspace manager purpose-built for AI coding agents. Unlike traditional terminal multiplexers like tmux, Herdr is designed from the ground up to be the runtime environment that coding agents run on — whether on your laptop, desktop, or a cloud server. As of August 2026, Herdr has amassed 24,579 GitHub stars and 328,537 total installs, with 488 community plugins and support for 19 different agent CLIs including Claude Code, Codex, and OpenCode.

Herdr’s session persistence is a standout feature — your work survives lid closing, and you can reattach from any device. This makes it ideal for developers who switch between machines or work with remote servers. The built-in help overlay, settings panel, and sidebar toggle make it more approachable than tmux’s steep learning curve, which is exactly where the Herdr Game comes in.

Introducing the Herdr Game — Learn by Doing#

The Herdr Game is not a tutorial video or a documentation walkthrough. It is an interactive, gamified learning experience that stages real Herdr topology inside your browser and validates your actions against live Herdr state. Each lesson presents a specific challenge — split a pane, create a workspace, send a prompt to an agent — and checks whether you executed it correctly.

The game was created by John Lindquist, well known in the developer education space for his work at egghead.io. His background in creating concise, high-impact developer tutorials is evident in the game’s design: every lesson is focused, immediately actionable, and builds on the previous one.

Curriculum Deep Dive — 34 Lessons Across 8 Chapters#

The game is structured as a progressive learning path. Each chapter introduces new concepts and builds on the skills from previous chapters. Here is what you will learn at each stage.

First Contact — Prefix Key, Help Overlay, Basic Navigation#

The opening chapter establishes the fundamentals. You learn Herdr’s prefix key (Ctrl+A by default, similar to screen), how to summon the help overlay, and basic navigation between tabs. This chapter is designed to get you productive within minutes — no configuration files to edit, no man pages to memorize.

Tabs & Panes — Splitting, Focusing, Resizing, Zooming#

This is where Herdr’s advantage over basic terminal multiplexers becomes clear. You learn to split the terminal into horizontal and vertical panes, move focus between them with keyboard shortcuts, resize panes dynamically, and zoom a pane to full screen. These operations are the bread and butter of daily Herdr use, and the game ensures you can execute them without thinking.

Workspaces — Multi-Project Management#

Workspaces are Herdr’s answer to managing multiple projects simultaneously. Each workspace maintains its own set of tabs and panes, letting you context-switch between projects without losing state. The game teaches you to create, switch between, and manage workspaces — a skill that becomes essential when you are juggling multiple coding agent sessions.

Power Tools — CLI, Socket API, Settings#

Beyond keyboard shortcuts, Herdr exposes a powerful CLI and a Socket API for programmatic control. This chapter covers the herdr command-line tool, how to interact with Herdr’s Unix socket for automation, and how to customize settings. For developers who want to script their terminal environment, this is where Herdr truly shines.

Advanced Combos — Chaining Shortcuts Like a Pro#

Once you know the individual shortcuts, the game teaches you to chain them. You learn patterns like “create a new tab, split it vertically, launch an agent in the right pane, and focus the left pane for notes” — all in a few keystrokes. This chapter transforms you from someone who knows shortcuts into someone who flows through the terminal.

Agent Operations — Prompt, Wait, Blocked-State, Transcripts#

This is the chapter that sets Herdr Game apart from any other terminal tutorial. You learn how to:

  • Prompt an agent: Send instructions to a coding agent running in a pane
  • Wait for completion: Monitor agent output and detect when a task is done
  • Handle blocked states: Recognize when an agent is waiting for input and unblock it
  • Read transcripts: Review agent session history for debugging and auditing

These skills are essential for anyone using AI coding agents in production. The game’s practice agents simulate real Claude and Codex behavior, including blocking states and multi-step interactions, so you learn to handle real-world scenarios without risking your own API credits.

Technical Architecture — How the Game Works#

The Herdr Game is built on a clever technical foundation. Each player gets an isolated Herdr session running inside a Vercel Sandbox. When you execute a command in the game’s embedded terminal (powered by wterm), it runs against a real Herdr instance. The game then queries Herdr’s state — active tabs, pane layout, current workspace — and compares it against the lesson’s validation criteria.

This means the skills you learn in the game transfer directly to production. You are not practicing against a simulation or a mock; you are using the same Herdr binary that runs on your machine. The only difference is that the game’s Herdr session is ephemeral and sandboxed.

The frontend stack — Next.js 16, React 19, TypeScript, and Tailwind CSS 4 — delivers a smooth, responsive experience. The wterm terminal emulator provides accurate terminal rendering, so keyboard shortcuts and terminal output behave exactly as they would in a native terminal.

No API Key Needed — The Practice Agent System#

One of the most thoughtful design decisions in the Herdr Game is the practice agent system. The agent lessons use deterministic mock programs that simulate Claude and Codex behavior — including prompt responses, completion signals, and blocked states — without making any actual API calls.

This means you can learn agent workflows without:

  • Signing up for an API account
  • Providing a credit card
  • Spending API credits on practice sessions
  • Waiting for slow model responses during learning

The practice agents are fast, predictable, and designed specifically for teaching. They respond instantly, demonstrate specific behaviors on demand, and can be reset between lessons. This makes the learning loop tight — try, fail, learn, retry — without the friction of real API latency.

Who Is This For? — Developers, Agent Operators, Terminal Enthusiasts#

The Herdr Game serves three distinct audiences:

Developers new to Herdr will find the game the fastest way to go from zero to productive. Instead of reading documentation and experimenting, you get structured lessons with immediate feedback. The game eliminates the “blank terminal” problem — you always know what to do next.

Experienced terminal users switching from tmux or screen will appreciate the focused lessons on Herdr-specific features like agent operations and workspace management. The game highlights what makes Herdr different, not just the basics you already know.

AI agent operators — developers who run Claude Code, Codex, or other coding agents — will find the agent operations chapter invaluable. Learning to handle blocked states, read transcripts, and manage multiple agent sessions is directly applicable to daily workflow.

FAQ#

Is the Herdr Game free to play?#

Yes, the Herdr Game is completely free. You do not need to create an account, provide an API key, or enter any payment information. Just open the game in your browser and start playing.

Do I need to install Herdr to play the game?#

No. The game provides an isolated Herdr session running inside a Vercel Sandbox. You interact with it through the embedded terminal in your browser. However, the skills you learn transfer directly to a locally installed Herdr instance.

How long does it take to complete the Herdr Game?#

Most players complete the 34 lessons across 8 chapters in 2 to 4 hours, depending on their familiarity with terminal multiplexers. The game is designed to be completed in a single sitting or spread across multiple sessions.

What is the difference between Herdr and tmux?#

Herdr is purpose-built for AI coding agents, while tmux is a general-purpose terminal multiplexer. Herdr detects 19 different agent CLIs, offers session persistence across devices, has a plugin ecosystem of 488 plugins, and provides built-in agent operations support. tmux is more mature and has broader community knowledge, but lacks AI-specific features.

Can I contribute to the Herdr Game?#

Yes, the Herdr Game is open source under the Apache 2.0 license and hosted on GitHub. You can contribute new lessons, fix bugs, improve documentation, or extend the game’s features. The community is actively growing, and contributions are welcome.
