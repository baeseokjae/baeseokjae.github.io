Quick Start — Run Your First AI Agent in 30 Seconds#

Getting started with awesome-llm-apps requires only Python 3.10+ and an API key from any supported LLM provider:

git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
cd awesome-llm-apps
pip install -r requirements.txt
export OPENAI_API_KEY="your-api-key"
python ai_agents/starter_agents/smart_assistant.py

That is it. The smart assistant agent will begin responding to queries with full conversational memory, tool use, and multi-step reasoning. For developers who prefer a visual interface, many templates include Streamlit or Gradio frontends that launch automatically.

Category 6 — RAG (Retrieval-Augmented Generation): From Basic to Agentic#

The repository includes over 20 RAG tutorials that progress from basic implementations to advanced agentic patterns:

Basic RAG — Simple retrieve-and-generate pipeline using vector search with OpenAI embeddings and ChromaDB.

Advanced RAG — Chunking strategies, metadata filtering, hybrid search (vector + keyword), and re-ranking for improved retrieval quality.

Agentic RAG — The agent decides when to retrieve, what queries to run, and whether the retrieved information is sufficient. Key patterns include:

  • Self-Grading RAG — the agent evaluates retrieved documents for relevance and re-queries if results are insufficient
  • Corrective RAG — the agent detects hallucinations or contradictions in retrieved content and corrects them
  • Hybrid Search RAG — combines vector similarity search with keyword search (BM25) for comprehensive retrieval
  • Knowledge Graph RAG — extracts entities and relationships from documents, builds a knowledge graph, and queries it alongside vector search

Category 7 — MCP AI Agents: Tool Integration via Model Context Protocol#

  • GitHub MCP Agent — reads repositories, creates issues, reviews pull requests, and manages projects
  • Notion MCP Agent — queries and updates Notion databases, pages, and properties
  • Browser MCP Agent — controls a headless browser for web automation and data extraction
  • Travel MCP Agent — searches flights, hotels, and activities via travel APIs

MCP provides a standardized interface that decouples agent logic from tool implementations. Any MCP-compatible tool can be swapped in without changing the agent code.

Category 10 — LLM Apps with Memory: Cross-Session Personalization#

Memory is a key differentiator in the awesome-llm-apps 2026 collection. Templates in this category implement persistent, cross-session memory for personalization:

  • Conversation Memory — stores chat history and user preferences across sessions
  • Entity Memory — remembers facts about people, places, and things mentioned in conversations

Memory implementations use vector databases (ChromaDB, Pinecone, Weaviate) for semantic retrieval and SQLite for structured data. The memory layer enables agents to provide increasingly personalized responses as they accumulate user history.

Category 11 — LLM Optimization & Fine-Tuning: Cut Costs, Boost Quality#

This category focuses on making LLM applications more efficient and cost-effective:

  • Model Routing — sends simple queries to cheaper models and complex queries to premium models
  • Fine-Tuning Templates — scripts for fine-tuning open-source models (Llama, Qwen, Mistral) on custom datasets

FAQ#

What is awesome LLM apps 2026?#

Awesome LLM Apps 2026 refers to the Shubhamsaboo/awesome-llm-apps GitHub repository, the largest open-source collection of AI agent templates with 128,721 stars. It contains over 100 hand-built, end-to-end tested AI agents, agent skills, and RAG applications across 15 categories, all under the Apache-2.0 license.

Can I use awesome-llm-apps templates for commercial projects?#

Yes. The repository is licensed under Apache-2.0, which grants permission to use, modify, distribute, and sell derivative works without royalty payments. This makes it ideal for startups, agencies, and enterprises building commercial AI products.

What LLM providers does awesome-llm-apps support?#

The repository supports over 10 LLM providers including OpenAI (GPT), Anthropic (Claude), Google (Gemini), DeepSeek, Meta (Llama), Alibaba (Qwen), xAI (Grok), Cohere, and Google (Gemma). Templates use environment variables for API configuration, making provider switching straightforward.

Do I need GPU hardware to run these AI agents?#

No. Most templates use cloud-based LLM APIs (OpenAI, Anthropic, Google, etc.) and run on standard CPU hardware. The agents make API calls to remote models, so a laptop or a $5/month VPS is sufficient for development and production deployment.

What is the difference between basic RAG and agentic RAG?#

Basic RAG follows a fixed retrieve-then-generate pipeline: it searches a vector database and passes results to the LLM. Agentic RAG gives the agent control over the retrieval process — it decides when to retrieve, what queries to formulate, whether results are sufficient, and whether to re-query or correct retrieved information. Agentic RAG produces more accurate results for complex queries but requires more sophisticated orchestration.
