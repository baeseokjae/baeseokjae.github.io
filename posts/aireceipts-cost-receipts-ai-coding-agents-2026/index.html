What is aireceipts?#

aireceipts is an open-source CLI tool (npm package aireceipts-cli, v0.11.0, Apache-2.0 license) that generates itemized cost receipts for AI coding agents including Claude Code, Codex CLI, Cursor, Gemini CLI, and OpenCode. It runs entirely on your local machine, requires no account or cloud upload, and produces deterministic, golden-tested receipts with prices cited directly from vendor pricing pages. Launched July 2, 2026, it reached 31 GitHub stars within three weeks and is the first serious attempt at a standardized cost-tracking layer for the AI coding agent ecosystem.

The Invisible Cost Problem — Why AI Coding Agent Costs Matter#

AI coding agents have transformed how developers write software, but they have introduced a new blind spot: cost visibility. When a developer runs claude code or fires up Codex CLI, tokens flow through the model API in real time. The output — code, diffs, explanations — appears instantly. The cost, however, remains invisible until the monthly API bill arrives.

The Silent Token Drain#

A typical Claude Code session using Opus 4.8 can cost between $0.15 and $0.50 depending on tool call frequency and cache hit rate, according to example receipts in the aireceipts README. A developer running ten such sessions per day spends $1.50 to $5.00 daily — $45 to $150 monthly — on a single agent. Multiply that across a team of five engineers, and the monthly burn rate reaches $225 to $750 for Claude Code alone, before accounting for Codex CLI, Cursor, or other agents.

The problem compounds when agents enter stuck retry loops, thrash context windows, or process trivial spans. These waste patterns are invisible to the developer in real time. Without per-session cost data, teams have no way to distinguish between a $0.05 quick answer and a $2.00 debugging spiral.

Why Existing Solutions Fall Short#

Before aireceipts, developers had three options for tracking AI coding costs:

  1. Manual estimation — Guess based on rough token counts and published pricing. Inaccurate and impractical for daily use.
  2. Vendor dashboards — Anthropic and OpenAI provide usage dashboards, but these aggregate across all API calls, not per-agent-session. A single API key may serve production traffic, batch jobs, and agent sessions simultaneously, making agent-specific cost impossible to isolate.
  3. Custom scripts — Parse log files and calculate costs manually. Fragile, time-consuming, and different for every agent.

None of these approaches provide the real-time, per-session, itemized cost data that teams need to manage their AI coding spend effectively.

How aireceipts Works — The Meter, The Receipt, The PR#

aireceipts operates across three surfaces, each designed for a different moment in the development workflow.

Live Statusline (The Meter)#

While an AI coding agent is running, aireceipts displays a live cost meter directly beneath the agent’s input box. This statusline updates in real time, showing the running token count and estimated cost for the current session. Developers can see costs accumulating as they work, creating immediate feedback that encourages cost-conscious behavior — shorter prompts, better cache utilization, and earlier termination of unproductive sessions.

Itemized Post-Session Receipt (The Receipt)#

When a session ends, aireceipts prints a full itemized receipt showing:

  • Total tokens consumed (input, output, cached input)
  • Cost per model tier (e.g., Opus 4.8 vs. Sonnet 5 vs. Haiku 4.5)
  • Number of tool calls and their individual costs
  • Cache hit rate and savings
  • Session duration
  • A “cheaper-model” line showing what the same session would have cost on an alternative model

The cheaper-model line is arithmetic, not predictive — it takes the exact same token counts and applies the alternative model’s published price. This gives developers a concrete, trustworthy number for model selection decisions.

PR Comment Attachment (The Receipt in Review)#

aireceipts can attach the itemized receipt as a comment on the associated pull request. This makes cost data visible during code review, enabling teams to discuss not just what the code does, but what it cost to produce. Over time, this creates a cost-per-PR metric that feeds into engineering budgeting and planning.

ObservAgent#

ObservAgent (12 GitHub stars, launched March 2026) provides a real-time web dashboard at localhost:4999 for Claude Code sessions. It monitors cost, tool usage, latency, and subagent timelines through Claude Code hooks with zero configuration. Its strength is the visual dashboard — richer than aireceipts’ terminal output. However, it supports Claude Code only, has no PR-level cost attachment, and lacks waste detection or cheaper-model arithmetic.

Hydra#

Hydra is a macOS desktop app (Electron + React + TypeScript) that functions as a real-time ops dashboard for AI agent developers. It shows which agents are running, per-process CPU and memory usage, port mapping, git health, and network bandwidth, alongside Claude Code cost tracking. Its scope is broader than cost tracking — it is a system monitor for AI development. The macOS-only limitation and lack of multi-agent cost comparison make it a complementary rather than competing tool.

Sanbox Cloud#

Sanbox Cloud runs AI agents in isolated MicroVM sandboxes with persistent filesystems. It supports Codex, Claude Code, Cursor, CI, and terminal agents via the OpenCode SDK. LLM cost tracking and observability are on the roadmap but not yet available. As a cloud platform, it requires an account and is not local-first, which places it in a different category from aireceipts.

Iris MCP#

Iris is an MCP-native evaluation and observability tool with 1 GitHub star. It is focused on evaluation and observability through the MCP protocol. At its current stage, it is significantly less mature than aireceipts or ObservAgent and serves a different use case (evaluation rather than cost tracking).

Pricing Transparency — The Honesty Rules and Deterministic Receipts#

aireceipts distinguishes itself through a commitment to pricing accuracy that goes beyond what most cost-tracking tools offer.

Deterministic, Golden-Tested Receipts#

Every receipt in aireceipts is deterministic — given the same session log, the tool produces the exact same cost output every time. The receipt logic is golden-tested, meaning test fixtures capture expected outputs and any change to the calculation logic must update the fixtures. This eliminates the “black box” problem where developers cannot verify how a cost was calculated.

Cited Prices from Vendor Pages#

Each receipt cites the specific vendor pricing page used for each model’s rates. When aireceipts reports that a Claude Opus 4.8 turn cost $0.042, it can point to the Anthropic pricing page showing $5/MTok input and $25/MTok output. This traceability is critical for teams that need to audit or justify AI spending.

Daily CI Tripwire#

aireceipts runs a daily CI job that cross-checks its internal price table against an independent pricing dataset. If a vendor changes prices — which happens frequently in the rapidly evolving AI market — the CI tripwire catches the discrepancy and alerts the maintainer. This ensures that receipts remain accurate even as the pricing landscape shifts.

Anonymous Telemetry#

aireceipts collects anonymous telemetry by default (opt-out via AIRECEIPTS_TELEMETRY=off or DO_NOT_TRACK=1). The telemetry is minimal and does not include session transcripts, code, or any identifying information. It is used to understand which agents and features are most used, guiding development priorities. For teams with strict data policies, the opt-out is straightforward and well-documented.

Heuristic Waste Detection#

aireceipts includes heuristic pattern flags that detect common waste patterns during AI coding sessions:

  • Stuck loops — The agent repeats the same action multiple times without progress
  • Context thrash — The agent repeatedly loads and unloads large context windows
  • Trivial spans — The agent spends significant tokens on trivial operations

These flags appear on the receipt, giving developers actionable data about which sessions were efficient and which were wasteful. Over time, this data helps teams identify which types of tasks are cost-effective for AI agents and which are not.

Who Should Use aireceipts?#

aireceipts is valuable for several distinct audiences:

Individual Developers#

If you use Claude Code, Codex CLI, or Cursor regularly and want to understand your AI coding costs, aireceipts provides immediate visibility. The live statusline alone changes behavior — seeing costs accumulate in real time encourages more efficient prompting and earlier termination of unproductive sessions.

Engineering Teams#

For teams adopting AI coding agents at scale, cost tracking is essential for budgeting and optimization. aireceipts provides per-developer, per-session cost data that can be aggregated to understand team-level AI spend. The PR-level cost attachment makes cost visible in code review, creating a culture of cost awareness.

Engineering Managers and CTOs#

AI coding agent costs are a new line item in engineering budgets. Without data, it is impossible to know whether the spend is justified by productivity gains. aireceipts provides the data needed to make informed decisions about which agents to use, for which tasks, and at what cost ceiling.

Open Source Maintainers#

aireceipts itself is open source and welcomes contributions. Its architecture — deterministic receipts, golden tests, CI price verification — sets a high bar for transparency that other tools in the space would do well to follow.

Verdict — Is aireceipts the Standard for AI Agent Cost Tracking?#

aireceipts is the most comprehensive, transparent, and well-designed cost-tracking tool for AI coding agents available today. Its combination of multi-agent support, deterministic receipts, vendor-cited pricing, CI-verified accuracy, and heuristic waste detection makes it the first tool that can credibly claim to be a standard for AI coding cost tracking.

Strengths#

  • Multi-agent coverage — No other tool supports this many AI coding agents from a single interface
  • Deterministic accuracy — Golden-tested receipts with vendor-cited prices eliminate trust issues
  • PR-level visibility — Cost data in code review is a genuinely novel and valuable feature
  • Waste detection — Heuristic flags provide actionable optimization data
  • Local-first — No account, no upload, no cloud dependency

Limitations#

  • Cursor depth — Session totals only, no per-turn granularity (a Cursor limitation, not an aireceipts one)
  • Anonymous telemetry on by default — Privacy-conscious users must opt out
  • Young project — 31 GitHub stars and v0.11.0 means the project is still early; long-term maintenance is unproven
  • No dashboard — Terminal output and PR comments are the only interfaces; no web dashboard like ObservAgent

The Bottom Line#

aireceipts fills a genuine gap in the AI development toolchain. As AI coding agents become more powerful and more widely adopted, the need for cost transparency will only grow. aireceipts is well-positioned to become the standard tool for this purpose, provided it continues to develop and attract community support. For any developer or team using AI coding agents and wanting to understand their costs, aireceipts is the tool to use today.

FAQ#

How does aireceipts calculate costs without an API key?#

aireceipts does not make API calls to calculate costs. It parses the session log output from the AI coding agent, counts the tokens consumed (input, output, and cached input), and multiplies by the published per-token rates from the vendor’s pricing page. The price table is embedded in the tool and verified daily by a CI tripwire against an independent dataset.

Does aireceipts send my code or session data anywhere?#

No. aireceipts is fully local — transcripts never leave your machine. The only data that leaves is anonymous telemetry (enabled by default, opt-out available) which includes feature usage statistics but no code, no prompts, and no session content. You can verify this by inspecting the open source code.

Can I use aireceipts with Cursor?#

Yes, but with limited depth. Cursor does not expose per-turn logs through its interface, so aireceipts can only provide session-level totals for Cursor sessions. For Claude Code, Codex CLI, and Gemini CLI, aireceipts provides full per-turn itemized receipts.

How often does aireceipts update its pricing data?#

aireceipts includes a daily CI tripwire that cross-checks its internal price table against an independent pricing dataset. If a vendor changes prices, the CI job catches the discrepancy and alerts the maintainer. The price table is also updated manually with each release. You can always check the latest prices in the source code or run aireceipts --prices to see the current table.

Is aireceipts free to use?#

Yes, aireceipts is open source under the Apache-2.0 license and completely free to use. There are no paid tiers, no accounts, and no usage limits. You install it via npm (npm install -g aireceipts-cli) and it works immediately with your existing AI coding agents.
