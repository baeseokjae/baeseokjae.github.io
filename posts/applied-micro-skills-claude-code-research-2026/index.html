What Are Applied Micro Skills for Claude Code?#

Applied micro skills are modular, reusable instruction files that teach Claude Code and similar AI coding agents (such as Codex) how to perform specific empirical research tasks. Unlike general-purpose AI coding assistance, these skills are purpose-built for the applied microeconomics and social science research workflow. Each skill encapsulates domain knowledge, best practices, and validated methodology into a prompt that the agent loads and follows.

The flagship repository, launched in July 2026 by Kenneth Khoo, contains 18 skills organized across the full research pipeline. The skills ecosystem has grown rapidly — Claude Skills Hub now indexes over 42,800 skills, with 1,331 in the Research category alone. This represents a fundamental shift in how empirical researchers interact with AI tools: instead of prompting a general assistant and hoping for correct econometric methodology, researchers load a specialized skill that has been tested against established benchmarks.

The skills fall into five major categories: reproducibility and verification, LLM-assisted classification, econometrics and data infrastructure, publication output, and literature review. Each category addresses a specific pain point in the empirical research workflow that has traditionally required significant manual effort or specialized programming knowledge.

The Reproducibility Crisis and the AI Solution#

The reproducibility crisis in empirical research is well-documented. A landmark Nature survey of 1,500 scientists found that over 70% of researchers have tried and failed to reproduce another scientist’s experiments. In economics and political science, the problem is particularly acute for computational work, where codebases may span multiple languages (Stata, R, Python), rely on proprietary data, or simply lack documentation.

Recent evidence shows that AI-assisted workflows can dramatically improve this situation. Xu & Yang (2026) demonstrated an automated full-paper replication workflow that analyzed 384 studies and 3,523 empirical models from top political science journals published between 2010 and 2025. Their findings are striking: reproducibility rates rose from 20.8% before the DA-RT (Data Access and Research Transparency) adoption to 82.5% after. Conditional on accessible replication packages being available, 92.1% of papers were fully or largely reproducible (234 out of 254 papers).

This is precisely where applied micro skills for Claude Code enter the picture. Rather than requiring researchers to manually audit code, check data integrity, and verify statistical outputs, these skills automate the mechanical verification process. The key insight is that many reproducibility failures follow predictable patterns — missing data transformations, incorrect standard error calculations, misaligned variable definitions — that can be systematically checked by an AI agent equipped with the right domain knowledge.

Core Reproducibility and Verification Skills#

Adversarial Empirical Review — The Flagship Audit#

The adversarial-empirical-review skill is the centerpiece of the applied-micro-skills collection. It takes an adversarial approach to reproducibility: instead of reading code to understand what the author intended, it independently recomputes every table number from the underlying data and flags discrepancies.

This skill operates by:

  1. Extracting every reported statistic from an empirical table
  2. Tracing each number back to the specific data transformation and estimation command that produced it
  3. Recomputing the result independently using the same data
  4. Reporting a discrepancy log with exact differences

The methodology treats reproducibility as a mechanical verification problem rather than a code-reading exercise. This is a critical distinction. Traditional code review asks “does the code do what the author says it does?” Adversarial empirical review asks “does the data produce the numbers in the table?” — a fundamentally more verifiable question.

LLM-Assisted Classification Methods for Research#

LLM-based classification has become a common tool in empirical social science research, but it comes with documented failure modes. The applied-micro-skills collection addresses these with four specialized skills that form a complete classification pipeline.

Annotator Input Parity Check#

The annotator-input-parity-check skill verifies that the input data fed to an LLM classifier matches what a human annotator would see. This addresses a subtle but critical failure mode: if the LLM receives different context, formatting, or preprocessing than a human annotator, the classification task changes fundamentally. The skill systematically compares the LLM’s input representation against the raw source material and flags any discrepancies in tokenization, truncation, or context window usage.

LLM Gold-Bound Failure Check#

The llm-gold-bound-failure-check skill addresses the precision ceiling problem in LLM classification. Even a well-calibrated LLM classifier has an upper bound on accuracy determined by the quality of the gold-standard labels. This skill:

  • Estimates the theoretical maximum achievable accuracy given label noise
  • Compares actual LLM performance against this bound
  • Identifies cases where the LLM is performing at or near the noise ceiling (meaning further prompt engineering is futile)
  • Flags instances where the LLM outperforms the gold standard (suggesting label errors)

LLM Campaign Drift Gate#

The llm-campaign-drift-gate skill monitors classification quality over time during large-scale LLM annotation campaigns. LLM behavior can drift due to model updates, API changes, unpinned model aliases, or subtle shifts in prompt interpretation. This skill:

  • Periodically evaluates a held-out validation set
  • Detects statistically significant changes in classification performance
  • Automatically halts the campaign when drift exceeds a threshold
  • Generates a diagnostic report identifying the likely source of drift

Adjudication Sheets for Human Review#

The adjudication-sheets skill produces structured spreadsheets that present LLM classification results alongside the source text, confidence scores, and flagged uncertainty regions for human review. This bridges the gap between automated classification and human oversight, enabling efficient targeted review of the most uncertain cases rather than full manual re-annotation.

Econometrics and Data Infrastructure Skills#

Event Study CARs — Validated Against Stata#

The event-study-cars skill implements cumulative abnormal return (CAR) calculations for event studies, a staple of empirical corporate finance and accounting research. Critically, this skill has been validated against Stata’s eventstudy2 package, ensuring that results are directly comparable to the dominant software in the field. This cross-validation is essential for researchers who need to transition between Stata and Python workflows without introducing methodological discrepancies.

WRDS Connection Guard and Query Patterns#

The WRDS (Wharton Research Data Services) connection guard skill manages authenticated access to one of the most widely used databases in empirical finance research. It handles:

  • Secure credential management
  • Connection retry logic for the WRDS PostgreSQL interface
  • Standard query patterns for Compustat, CRSP, and other common datasets
  • Rate limiting and query optimization for large extractions

Stata Integration via pystata#

The Stata integration skill uses the pystata Python package to call Stata directly from within Claude Code workflows. This is particularly valuable for researchers who maintain legacy Stata code or need to validate Python results against established Stata implementations. The skill handles data transfer between Python and Stata environments, manages Stata session state, and captures output for downstream processing.

Publication-Grade Tables, Figures, and Citations#

The applied-micro-skills collection includes several skills focused on the final stages of the research pipeline. The latex-empirical-tables skill produces publication-quality LaTeX tables directly from estimation results, handling standard econometric table formatting conventions including significance stars, standard errors in parentheses, and model specification columns. The stata-style-figures skill generates figures that match the visual style of Stata graphics, maintaining consistency for researchers who mix Stata and Python workflows. The cite-placement skill automates citation placement in manuscripts, and the latex-to-word skill handles the conversion from LaTeX to Word format for journal submission systems that require .docx files.

Literature Review Automation#

The lit-review-orchestrator skill coordinates multi-engine deep searches across academic databases, preprint servers, and web sources. It:

  • Formulates search queries from a research question
  • Executes parallel searches across multiple engines
  • Deduplicates and ranks results by relevance
  • Extracts key findings and methodology details
  • Produces a structured literature review summary

This skill addresses a significant bottleneck in the research process. A thorough literature review can take weeks of manual effort; the orchestrator reduces this to hours while maintaining systematic coverage.

How to Get Started with Applied Micro Skills#

Getting started with applied micro skills for Claude Code requires:

  1. Install Claude Code or a compatible agent — These skills work with Claude Code, Codex, and other AI coding agents that support skill/instruction loading.

  2. Clone the repository — git clone https://github.com/kennethkhoocy/applied-micro-skills provides access to all 18 skills.

  3. Load the relevant skill — Each skill is a standalone instruction file. Load it into your agent session with the appropriate command for your agent (e.g., /skill for Claude Code).

  4. Provide your data and specifications — The skills are designed to work with your research data. For the adversarial-empirical-review skill, provide the empirical table and the underlying dataset. For the event-study-cars skill, provide the event dates and return data.

  5. Review the output — Each skill produces structured output with clear documentation of what was done, how it was validated, and any discrepancies found.

For researchers new to AI-assisted workflows, starting with the reproducibility auditing skills (adversarial-empirical-review or Referee 2) provides the most immediate value, as these skills address a universal pain point in empirical research.

Q: How does adversarial empirical review differ from traditional code review?
