On July 31, 2026, Cursor removed the dollar cost display from its usage page, replacing it with opaque token amounts — a change that stripped users of the ability to track their actual spending in real time. This move has ignited a firestorm of criticism from the developer community, with many accusing the AI coding editor of deliberately hiding costs to maximize revenue under its new SpaceXAI ownership.

The Change: What Cursor Actually Did#

Cursor’s usage page previously showed a clear dollar breakdown of how much users had spent on on-demand (pay-per-token) usage beyond their plan limits. Users could see daily, weekly, and monthly spending in real dollars, making it easy to track costs and set mental budgets.

The change, deployed around July 31, 2026, replaced the dollar graph with token amounts. Instead of seeing “$12.50 spent today,” users now see something like “125,000 tokens consumed.” For the average developer, token counts are meaningless without a calculator — especially since different models cost different amounts per token.

A Cursor employee confirmed the change on the official forum, stating that the dollar graph was “intentionally removed because included plan usage shown as $ was confusing to some users.” The same employee acknowledged that the CSV export also stopped including cost data, though they claimed this was accidental and later fixed.

The timing is notable. The change came just days after Cursor launched its Start plan for the India market (July 28) and its Cursor Router intelligent model routing feature (July 22) — suggesting a coordinated push toward usage-based monetization.

Community Backlash — Why Users Are Furious#

The Hacker News discussion about Cursor removing cost information reached 204 points, with users expressing anger, frustration, and a sense of betrayal. The sentiment is best summarized by one commenter who called it “a textbook enshittification pattern — first you build dependency, then you extract.”

The Trust Problem#

Users who relied on the dollar breakdown to track daily spending found themselves suddenly blind. With on-demand usage billing — where every API call beyond plan limits incurs per-token charges — the ability to monitor costs in real time is essential. Without it, users risk surprise bills at the end of the month.

One user reported spending $500–$1,500 per month on Cursor on-demand usage. Another noted that per-request costs for premium models like Opus 4.5–4.6 range from $0.05 to a staggering $45.74 for a single request. When you cannot see dollar amounts accumulating, it becomes nearly impossible to make informed decisions about which model to use or when to stop.

The Team Management Problem#

For teams sharing a single on-demand usage cap, the change is even more damaging. Team leads previously used the dollar breakdown to see which members were consuming the most on-demand credits. Without that visibility, managing a team budget becomes guesswork.

The SpaceXAI Factor#

Many commenters pointed to Cursor’s acquisition by SpaceXAI (Elon Musk) as the root cause. The narrative is straightforward: pre-acquisition Cursor was developer-friendly and transparent; post-acquisition Cursor is aggressively monetizing its user base. Whether this perception is fair or not, it has become the dominant story in the community.

“Cursor was the darling of the AI coding world. Now it feels like every change is designed to extract more money from the people who made it successful.” — HN commenter

The Bigger Picture: Cursor’s Pricing Trajectory#

The usage page change is not an isolated incident. It is part of a clear pattern of pricing changes at Cursor throughout 2026:

Bugbot Goes Usage-Based#

In May 2026, Cursor switched Bugbot from a flat $40/seat/month to usage-based billing. The average Bugbot run now costs $1.00–$1.50 depending on PR size. Existing customers were grandfathered until their next renewal after June 8, 2026, but new customers face the variable pricing model immediately.

The On-Demand Pricing Reality#

Cursor’s pricing structure now works like this:

The Ultra subscription, at $200/month, includes approximately $500 worth of API requests based on user reports. But heavy users report blowing through that allocation quickly — some have maxed out 20x the Ultra membership limit in a single day. When you exceed plan limits, on-demand pricing kicks in, and costs can spiral rapidly.

The Token Economy Problem#

Abstracting costs into tokens is a well-known strategy in consumer technology. Mobile data plans, in-app currencies, and cloud credits all use the same approach: make the unit of consumption abstract enough that users cannot easily calculate real costs. The psychology is simple — people spend more when they don’t know exactly how much they’re spending.

For Cursor, the token display serves a dual purpose: it reduces support complaints about confusing dollar amounts (as the Cursor employee claimed) while simultaneously making it harder for users to track their actual spending. Whether intentional or not, the effect is the same.

How Competitors Handle Pricing Transparency#

Microsoft-owned Copilot has maintained consistent pricing without the sudden changes that have characterized Cursor’s 2026.

Claude Code (Anthropic)#

Claude Code by Anthropic uses a straightforward API pricing model. Users pay for what they use through the Anthropic API, with clear per-token pricing published on the pricing page. There is no subscription tier that obscures actual costs — you see exactly what you pay per request.

Codex (OpenAI)#

OpenAI’s Codex CLI offers a free tier with limited usage and a pay-as-you-go model for heavy users. Like Claude Code, the pricing is API-based and transparent. Users know exactly what each request costs.

What This Means for the AI Coding Tool Market#

The Cursor pricing controversy is a signal about where the AI coding tool market is heading in 2026 and beyond.

The Monetization Phase#

The AI coding tool market has moved from the land-grab phase (2023–2025), where companies focused on user acquisition and market share, to the monetization phase (2026 onward), where the pressure to generate revenue is intensifying. Cursor, now under SpaceXAI ownership, is leading this shift with aggressive pricing changes.

User Loyalty Is Being Tested#

The backlash against Cursor’s pricing opacity is a stress test for user loyalty in the AI tool space. Developers are a uniquely vocal and mobile user base — they have the skills, tools, and motivation to switch platforms quickly. The HN discussion shows that many users are already evaluating alternatives:

  • “I switched to Claude Code and haven’t looked back”
  • “Copilot Max at $100/mo is actually cheaper than my Cursor on-demand bill”
  • “Codex CLI is free and does everything I need”

The Enshittification Narrative#

The term “enshittification” — coined by writer Cory Doctorow to describe platforms that degrade quality to extract more value from users — has become the dominant frame for understanding Cursor’s 2026 changes. The pattern fits: Cursor built a loyal user base with a great product, then began extracting value through opaque pricing, reduced transparency, and aggressive monetization.

Should You Stay or Switch?#

The answer depends on your usage patterns and priorities.

Stay with Cursor if:#

  • You stay within your plan limits and rarely use on-demand pricing
  • You value Cursor’s specific features (Composer, Tab, Bugbot) over competitors
  • You are willing to manually track your token consumption
  • Your team has a dedicated budget that doesn’t require per-user tracking

Consider switching if:#

  • You regularly exceed plan limits and incur on-demand charges
  • You need to track team member spending
  • Pricing transparency is important to your workflow
  • You are concerned about the direction of Cursor under SpaceXAI

Conclusion — A Warning for the AI Tool Industry#

Cursor’s decision to remove cost information from its usage page is more than a UX change — it is a strategic signal about the company’s direction under SpaceXAI ownership. By replacing dollar amounts with token counts, Cursor has made it harder for users to make informed decisions about their spending, eroding the trust that made the platform successful in the first place.

The broader lesson for the AI coding tool industry is clear: developers value transparency. In a market where switching costs are low and alternatives are plentiful, opaque pricing is a competitive disadvantage, not a moat. Companies that prioritize clear, honest pricing — like GitHub Copilot, Claude Code, and Codex — are well-positioned to capture users fleeing platforms that prioritize extraction over trust.

For Cursor users, the message is equally clear: track your usage carefully, know your alternatives, and vote with your wallet. The AI coding tool market is still young, and the companies that treat their users as partners rather than revenue sources will be the ones that survive.

Frequently Asked Questions#

Why did Cursor remove the dollar cost display from the usage page?#

A Cursor employee stated on the official forum that the dollar graph was intentionally removed because “included plan usage shown as $ was confusing to some users.” The change replaced dollar amounts with token counts, making it harder for users to track real-time spending on on-demand usage.

Can I still see how much I’m spending on Cursor?#

Not directly through the usage page. You can manually calculate costs by tracking token consumption and multiplying by the per-model token rates, but Cursor no longer provides a real-time dollar breakdown. The CSV export initially lost cost data as well, though Cursor claimed this was accidental and partially restored it.

How much does Cursor on-demand usage actually cost?#

User reports indicate per-request costs range from $0.05 to $45.74 for premium models like Opus 4.5–4.6. Heavy users report monthly on-demand bills of $500–$1,500. The Ultra subscription ($200/month) includes approximately $500 worth of API requests, but heavy users can exhaust this allocation quickly.

Is Cursor still the best AI coding editor?#

Cursor remains a powerful tool with unique features like Composer, Tab, and Bugbot. However, competitors like GitHub Copilot, Claude Code, and Codex have closed the feature gap significantly. The best choice depends on your usage patterns, budget, and whether pricing transparency matters to you.

How does Cursor pricing compare to GitHub Copilot in 2026?#

GitHub Copilot offers Free, Pro ($10/mo), Pro+ ($39/mo), and Max ($100/mo) tiers with a transparent AI Credits system. Cursor’s Pro ($20/mo) and Ultra ($200/mo) plans are more expensive, and its on-demand usage costs can add hundreds to thousands of dollars per month. For most users, Copilot offers better value with clearer pricing.
