Piny is a visual editor for Tailwind CSS that runs directly inside VSCode, Cursor, and Windsurf, letting you style React, Next.js, and Astro projects by clicking and dragging instead of writing utility classes by hand. Built by Pinegrow — a company with over a decade of visual web editing experience — Piny edits your source code directly with no proprietary formats, no cloud lock-in, and no account required on the free tier.

What Is Piny? A Visual Editor for Tailwind CSS Inside Your IDE#

Piny is a VS Code extension (also available on Cursor and Windsurf) that brings visual editing capabilities to Tailwind CSS projects. Instead of switching between your code editor and a browser-based design tool like Webflow or Figma, Piny lets you adjust Tailwind classes, inspect styles, navigate components, and even drag-and-drop elements — all within your IDE.

The extension was created by Matjaz Trontelj and published by Pinegrow Pte. Ltd., the same team behind Pinegrow Web Editor, a desktop visual editor that has been around for over a decade. Piny is not a rewrite of Pinegrow for VS Code — it is a purpose-built tool designed for modern JavaScript frameworks and the AI-assisted development workflow.

As of July 2026, Piny has 4,158 installs on the VS Code Marketplace with a 3-star rating from 3 reviews. The latest version is 0.0.20, published on July 2, 2025.

Key Features: What Can Piny Actually Do?#

Piny’s feature set is divided between its free tier and Pro tier. Here is what you get at each level:

Free Tier Features#

Visual Tailwind Controls — The core feature. When you select an element in your code, Piny shows a visual panel where you can adjust Tailwind CSS properties like spacing, colors, typography, borders, and shadows. Changes are written directly into your source code as Tailwind utility classes.

Class Inspector — Hover over any element to see all applied Tailwind classes, their computed values, and which ones are inherited versus explicitly set. This is particularly useful when debugging complex class combinations or when working with someone else’s code.

Component Navigation — A tree view of your project’s components, letting you jump between files without using the file explorer. This works especially well with React and Next.js projects where components are spread across multiple files.

AI Drag & Drop — An AI-powered feature that lets you rearrange elements visually. When you drag an element to a new position, Piny rewrites the JSX or template code to reflect the new structure. This is included in the free tier, which is notable since many tools reserve AI features for paid plans.

Pro Tier Features ($120/year or $15/month)#

Visual Select — Click on any element in your browser’s live preview and Piny jumps to the corresponding source code in your editor. This is the flagship Pro feature and it requires additional script integration in your project layout.

Multi-Element Editing — Select and modify multiple elements at once, applying the same Tailwind class changes across all of them. Useful for bulk style updates during redesigns.

Project Navigation — An enhanced version of Component Navigation that includes a full project map with dependency visualization, making it easier to understand how components relate to each other.

Custom Tailwind Theme — Edit your tailwind.config.js visually through a dedicated interface, including custom colors, spacing scales, breakpoints, and typography settings.

The free tier is genuinely free — no time limits, no account creation, no data collection, and no feature degradation after a trial period. This is unusually generous for developer tools and makes Piny risk-free to try.

Piny Pro costs $120 per year (billed annually) or $15 per month, with a 35% launch discount available. At full price, that is $10/month — comparable to a single SaaS subscription but significantly cheaper than visual design tools like Webflow ($23/month) or Framer ($20/month).

Framework Support: Astro, React, and Next.js with Tailwind CSS#

Piny supports three modern JavaScript frameworks, all requiring Tailwind CSS to be properly configured in the project.

React — Full support for JSX components, including functional components, hooks-based state, and conditional rendering. Piny understands React’s component tree and preserves component boundaries during visual edits.

Next.js — Works with both the Pages Router and App Router. Piny respects Next.js conventions like server components, client components, and layout files. The Component Navigation feature is particularly useful in Next.js projects where the file structure can be deep.

Astro — Supports .astro files with their unique component syntax. Piny handles Astro’s frontmatter, template expressions, and island architecture correctly.

Important limitation: Piny is NOT for static HTML projects or WordPress development. It requires a React, Next.js, or Astro project with Tailwind CSS properly configured and a functioning local development server. If you are working with plain HTML, PHP templates, or WordPress themes, Piny will not work — you would need Pinegrow Web Editor instead.

How Piny Complements AI Coding Agents#

One of the most interesting aspects of Piny is its positioning relative to AI coding tools. The creators explicitly designed Piny to complement AI agents, not compete with them.

Here is the reasoning: AI coding agents like GitHub Copilot, Cursor’s AI, and Claude Code are excellent at generating code from prompts, but they struggle with visual precision. When you ask an AI to “make the button 4 pixels more padding and change the border radius to 12px,” the AI might get it right, or it might change something else unintentionally. With Piny, you make those adjustments visually and see the exact Tailwind classes being written.

The workflow looks like this:

  1. Use an AI agent to generate the initial component structure and logic
  2. Use Piny to fine-tune the visual styling — spacing, colors, responsive breakpoints
  3. Use the Class Inspector to verify the AI-generated Tailwind classes are correct
  4. Use AI Drag & Drop to rearrange layout without touching code

This hybrid approach is faster than either method alone. The AI handles the heavy lifting of code generation, and Piny handles the pixel-perfect visual refinement that AI struggles with.

Getting Started: Installation and Setup Guide#

Installing Piny takes about two minutes:

  1. Open your editor’s extension marketplace (VSCode, Cursor, or Windsurf)
  2. Search for “Piny” by Pinegrow
  3. Click Install
  4. Open a React, Next.js, or Astro project with Tailwind CSS configured
  5. Start your local development server
  6. Open a .jsx, .tsx, or .astro file
  7. Click the Piny icon in the activity bar or use the command palette (Ctrl+Shift+P → “Piny: Open”)

Prerequisites:

  • Node.js 18 or later
  • A React, Next.js, or Astro project
  • Tailwind CSS v3 or v4 properly configured
  • A running local dev server (npm run dev or equivalent)
  • VS Code ^1.91.0 (or compatible editor)

For Visual Select (Pro only): You need to add a small script tag to your project’s layout file. The Piny documentation provides the exact snippet for each framework.

Pros and Cons: A Balanced Assessment#

Pros#

  • No lock-in. All edits are written directly to your source code as Tailwind utility classes. You can uninstall Piny and your code remains exactly as it was.
  • Genuinely free tier. No account, no time limit, no data collection, no upsells during use. This is rare and commendable.
  • Works across three IDEs. VSCode, Cursor, and Windsurf users all get the same experience.
  • AI Drag & Drop is free. Most tools charge extra for AI features.
  • Built on a decade of experience. Pinegrow has been making visual editors since 2013, so Piny is not a rushed MVP.
  • Complements AI tools. Designed to work alongside AI coding agents, not replace them.

Cons#

  • Limited framework support. Only React, Next.js, and Astro. No Vue, Svelte, Solid, or Angular support yet.
  • Small user base. 4,158 installs and only 3 reviews suggest early adoption. Community resources and third-party tutorials are scarce.
  • Requires a running dev server. You cannot use Piny on a static codebase without starting the development server first.
  • Visual Select requires setup. The flagship Pro feature needs additional script integration, which adds friction.
  • No WordPress or static HTML support. If you work with traditional web projects, Piny is not for you.
  • 3-star rating. While based on only 3 reviews, the rating suggests early users found room for improvement.

Verdict: Who Should Use Piny and Why#

Piny fills a specific niche that no other tool addresses: visual Tailwind CSS editing inside your code editor. If you work with React, Next.js, or Astro projects using Tailwind CSS, Piny is worth installing — the free tier costs nothing and gives you immediate value.

Use Piny if:

  • You use Tailwind CSS with React, Next.js, or Astro
  • You want to adjust styles visually without memorizing every Tailwind class
  • You use AI coding agents and want a visual refinement step
  • You value tools that edit source code directly with no lock-in
  • You are tired of switching between your editor and browser DevTools for styling

Skip Piny if:

  • You use Vue, Svelte, Solid, or Angular
  • You work with static HTML, WordPress, or PHP projects
  • You prefer writing Tailwind classes manually and have the class names memorized
  • You need a full visual CMS or design-to-code workflow

Piny is not trying to be Webflow or Figma inside your editor. It is a focused tool for one job — making Tailwind CSS styling faster and more visual — and it does that job well. The free tier is generous enough to be genuinely useful, and the Pro tier is reasonably priced for professionals who need the extra features.

At 4,158 installs and version 0.0.20, Piny is still early in its journey. But with a decade of Pinegrow experience behind it and a clear vision for how visual tools fit into the AI-assisted development workflow, Piny is a tool worth watching — and trying — in 2026.

Frequently Asked Questions#

Is Piny free to use?#

Yes, Piny has a genuinely free tier with no time limits, no account required, and no data collection. The free tier includes Visual Tailwind Controls, Class Inspector, Component Navigation, and AI Drag & Drop. Piny Pro ($120/year or $15/month) adds Visual Select, Multi-Element Editing, Project Navigation, and Custom Tailwind Theme editing.

Does Piny work with Vue or Svelte?#

No, Piny currently supports only React, Next.js, and Astro projects with Tailwind CSS. There is no support for Vue, Svelte, Solid, or Angular at this time. The Pinegrow team has not announced plans for additional framework support.

How is Piny different from Pinegrow Web Editor?#

Piny is a VS Code extension for visual Tailwind CSS editing in modern JavaScript frameworks (React, Next.js, Astro). Pinegrow Web Editor is a desktop application for static HTML and WordPress development. They serve different use cases and are designed to complement each other, not replace one another.

Does Piny work with Tailwind CSS v4?#

Yes, Piny supports both Tailwind CSS v3 and v4. The extension detects your Tailwind version and adjusts its visual controls accordingly. Make sure Tailwind CSS is properly configured in your project before using Piny.

Can I use Piny with GitHub Copilot or Cursor AI?#

Yes, Piny is designed to complement AI coding agents. You can use GitHub Copilot, Cursor AI, or Windsurf’s Cascade to generate component code, then use Piny to fine-tune the visual styling. The AI Drag & Drop feature in Piny’s free tier also uses AI to rearrange elements visually.
