What Is Nova? — Overview of the Deterministic Windows AI Agent#

Nova is an open-source Windows desktop AI agent launched on July 2, 2026, that solves the most persistent problem in AI automation: hallucinated actions. Unlike traditional AI agents that guess at screen coordinates and frequently click the wrong targets, Nova uses native Windows UI Automation (UIA) to interact with applications through their actual interface elements — buttons, menus, text fields, and dialog boxes — rather than blind pixel coordinates. This architectural choice, combined with a Python code sandbox, human-in-the-loop (HITL) confirmation for dangerous operations, and automatic file rollback from backups, makes Nova one of the most reliable Windows automation agents available in 2026.

Key Features — Voice Control, UI Automation, File Management, Browser Agent, Memory, and More#

Nova packs a comprehensive feature set that rivals established desktop assistants with thousands of stars. Here is what it offers out of the box:

Voice Control and Speech Recognition#

Nova supports both cloud-based and local speech-to-text through Groq API and Whisper.cpp, giving users flexibility depending on their privacy requirements and internet connectivity. Text-to-speech is handled through the Windows native TTS engine or cloud alternatives.

Native Windows UI Automation#

Instead of sending blind mouse clicks to fixed coordinates — the approach that causes most desktop agent failures — Nova uses Microsoft’s UI Automation (UIA) framework to identify and interact with actual UI elements. This means it can find the “Save” button by its accessibility name, not by guessing pixel (1024, 768) might be the right spot.

File Management with Rollback#

Every file operation Nova performs is backed up automatically. If the agent makes an unwanted change, users can roll back to the previous state — a safety net absent from virtually every competing Windows agent.

Browser Agent#

Nova includes a browser automation module that can navigate web pages, fill forms, extract data, and perform research tasks. This works alongside the desktop UI automation for seamless cross-application workflows.

Persistent Memory and Plan Management#

Nova uses SQLite for persistent storage of plans, conversation history, and application state. If the agent crashes or the system restarts, Nova can recover its in-progress tasks from the crash recovery database rather than starting from scratch.

Background Plan Execution#

Users can queue multiple plans and let Nova execute them in the background while they continue working. The agent manages its own task queue and reports results as each plan completes.

How Nova Achieves Deterministic Execution — Native UIA vs Blind Clicks, Sandbox, HITL#

The term “deterministic AI agent” might sound like an oxymoron to anyone familiar with the probabilistic nature of large language models. Nova does not eliminate LLM randomness — it eliminates the action randomness that plagues coordinate-based agents.

The Blind Click Problem#

Most desktop AI agents work by taking screenshots, asking an LLM to identify where to click, and then sending mouse events to those pixel coordinates. This approach fails when:

  • The screen resolution changes
  • The window is resized or moved
  • A different theme or DPI scaling is applied
  • The application updates its layout
  • Multiple monitors are in use

Each of these scenarios causes the agent to click the wrong location, producing a cascade of errors that the LLM cannot recover from without human intervention.

Nova’s UIA Solution#

Nova bypasses the entire coordinate-guessing problem by using Windows UI Automation, the same framework that screen readers and accessibility tools use. UIA provides a tree of all interactive elements on screen with their roles, names, and states. Nova’s executor queries this tree to find the exact element it needs — a button labeled “Submit,” a text field with the name “Search,” a checkbox with the state “unchecked” — and sends input directly to that element.

This approach is fundamentally more reliable because:

  • Element identity is stable — a button’s accessibility name does not change when the window moves
  • State is observable — Nova can check whether a button is enabled or disabled before clicking
  • Feedback is structural — after an action, Nova can verify the UI state changed as expected

Architecture Deep Dive — Agent Planner, Executor, Recovery Engine, Security Sandbox, Storage Layer#

Nova’s architecture is modular and well-documented, with over 220 automated tests covering each component.

Agent Planner#

The Planner module receives a user’s natural language request and breaks it down into a sequence of discrete steps. Each step is typed — UI action, file operation, code execution, or browser navigation — and validated before execution begins. The planner uses the LLM (via Groq or OpenRouter) for task decomposition but constrains the output to a structured plan format that the Executor can follow deterministically.

Executor#

The Executor is the heart of Nova’s deterministic guarantee. It takes each planned step and executes it through the appropriate channel:

  • UI steps → Windows UIA API
  • File steps → Sandboxed file system with automatic backup
  • Code steps → Python sandbox with restricted imports and no network access
  • Browser steps → Playwright-based browser automation

Each step reports success or failure with structured feedback. If a step fails, the Executor can retry with adjusted parameters or escalate to the user for guidance.

Recovery Engine#

Nova’s crash recovery system, documented in CRASH_RECOVERY.md, uses SQLite to persist the state of all active plans. On restart, Nova reads the recovery database and offers to resume interrupted plans. This is particularly valuable for long-running automation tasks that might take hours to complete.

Security Sandbox#

The sandbox module (modules/security/sandbox.py) restricts Python code execution to a safe subset of the language. Dangerous operations — file system writes outside allowed directories, network access, subprocess calls — are blocked by default. The sandbox also enforces system directory write protection, preventing Nova from modifying critical Windows system files.

Storage Layer#

SQLite serves as Nova’s persistent storage for conversation history, plan state, user preferences, and backup metadata. This lightweight approach keeps the agent self-contained with no external database dependencies.

Key Takeaways from the Comparison#

PyGPT is the most feature-rich desktop AI assistant with support for GPT-5, GPT-4, o1, o3, Gemini, Claude, Ollama, DeepSeek, Perplexity, and Grok. It offers chat, vision, voice, RAG, and image generation. However, it lacks Windows-native UI automation entirely and has no deterministic execution guarantees. PyGPT is a conversation tool, not an automation agent.

Skales is a cross-platform personal AI agent with goal-oriented autonomous task execution and a unique team mode for pairing two desktops. It supports Windows, macOS, Linux, Android, and iOS. But like PyGPT, it is not specifically deterministic or Windows-focused.

Windows Computer Use MCP provides 22 MCP tools for click, type, screenshot, OCR, and UI inspection on Windows. It works with any MCP-compatible agent. However, it has no built-in deterministic guarantees or HITL confirmation — it is a tool library, not a complete agent.

Clawbridge offers plain English commands, workflow recording, and bring-your-own-key (BYOK) for browser and desktop automation. It has no telemetry and no cloud server dependency. But it lacks deterministic execution and rollback support.

Nemo Assistant is a local-first floating desktop AI assistant for Windows with selection actions, OCR, notes, and tool-calling. It is Windows-native but limited in scope with no deterministic execution or rollback features.

Security Model — Code Sandbox, System Directory Protection, Permission Confirmation, File Rollback#

Nova’s security architecture is arguably its strongest differentiator. While most desktop agents operate with full system privileges and no oversight, Nova implements a defense-in-depth approach.

Python Code Sandbox#

When Nova executes Python code — whether from a user request or an automated plan — it runs inside a restricted sandbox that:

  • Blocks imports of dangerous modules (os, subprocess, shutil, ctypes)
  • Disables network access
  • Limits file writes to designated directories
  • Enforces a maximum execution time
  • Logs all operations for audit

System Directory Write Protection#

Nova maintains a blocklist of protected system directories including C:\Windows, C:\Program Files, and registry paths. Any attempt to write to these locations is intercepted and either blocked or escalated for HITL approval.

Human-in-the-Loop Confirmation#

For operations classified as dangerous — file deletion, software installation, registry modification, or execution of downloaded files — Nova pauses and presents the user with a clear description of what it is about to do. The user can approve, deny, or modify the operation. This confirmation is not a nuisance prompt for every action; Nova’s risk classifier only triggers HITL for operations that could cause irreversible damage.

Automatic File Rollback#

Before modifying any file, Nova creates a backup in its SQLite-backed storage. If the user decides the change was incorrect, they can instruct Nova to roll back to the pre-operation state. This is a safety net that no competing Windows agent offers.

Installation and Setup — Python 3.14, API Keys, Dependencies, Desktop UI#

Getting started with Nova requires Python 3.14 and a few API keys. The setup process is straightforward:

  1. Clone the repository: git clone https://github.com/KremlevLev/nova
  2. Install dependencies: pip install -r requirements.txt
  3. Configure API keys: Edit .env with your Groq and/or OpenRouter API keys
  4. Launch the desktop UI: python main.py

Nova supports both cloud inference (Groq, OpenRouter) and local inference (Whisper.cpp for speech-to-text, llama.cpp for LLM). The local mode is particularly valuable for users who need offline operation or have strict data privacy requirements.

The desktop UI provides a floating interface similar to Nemo Assistant, with a chat input area, plan queue display, and status indicators for active tasks.

Real-World Use Cases — Development Workflow, Desktop Automation, Voice-Controlled Operations#

Development Workflow Automation#

A developer can ask Nova to “set up a new React project in the workspace folder, install dependencies, and open it in VS Code.” Nova will create the directory, run npx create-react-app, install packages, and launch VS Code — all while backing up any files it modifies and asking for confirmation before touching existing code.

Desktop Automation#

For power users, Nova can automate repetitive Windows tasks: renaming batches of files, organizing downloads folders, filling out forms across multiple applications, extracting data from legacy software that has no API, and generating reports from multiple sources.

Voice-Controlled Operations#

With the voice module enabled, users can control their Windows desktop entirely by voice. “Nova, open Chrome, go to Gmail, and read me my latest emails” becomes a single voice command that the agent executes through UIA-driven browser interaction.

Research and Data Extraction#

Nova’s browser agent can navigate to multiple websites, extract structured data, and compile it into a spreadsheet or document — all without the user touching the keyboard.

Limitations and Early-Stage Considerations — Small Community, Russian-First Documentation, Windows-Only#

Nova is a very early-stage project with significant limitations that potential users should consider:

Small Community and Limited Track Record#

With only 7 GitHub stars as of mid-July 2026, Nova has virtually no community support. There are no third-party plugins, no community-contributed workflows, and limited troubleshooting resources. The project was created on July 2, 2026 — it is less than three weeks old at the time of this review.

Russian-First Documentation#

The README and most documentation are written in Russian, which may be a barrier for English-speaking users. While the code comments and variable names use English, the primary user-facing documentation requires translation or Russian language proficiency.

Windows-Only Limitation#

Nova is exclusively a Windows agent. Users on macOS or Linux cannot use it. This is by design — Nova’s core differentiator is Windows UIA integration — but it limits the addressable audience significantly.

LLM Dependency#

Despite its deterministic execution layer, Nova still depends on an LLM for task planning and natural language understanding. If the LLM misinterprets a request, the plan itself may be wrong, even if the execution is correct. The HITL layer catches dangerous operations, but subtle logical errors in plans may go undetected.

No Published Roadmap#

The repository does not include a public roadmap or contribution guidelines, making it difficult for potential contributors to understand the project’s direction or how to get involved.

Verdict — Who Should Use Nova in 2026?#

Nova is a promising but very early-stage project that addresses a genuine gap in the Windows AI agent ecosystem: reliable, deterministic desktop automation with enterprise-grade safety features.

Use Nova if:

  • You need a Windows automation agent that does not click the wrong targets
  • You value safety features like HITL confirmation, code sandboxing, and file rollback
  • You are comfortable with Russian-language documentation
  • You want to contribute to an early-stage open-source project with a well-architected codebase
  • You need offline-capable AI desktop automation

Wait or look elsewhere if:

  • You need cross-platform support
  • You require a mature, battle-tested solution with community support
  • You do not read Russian and need English documentation
  • You need a conversational AI assistant rather than an automation agent (PyGPT is better suited)

Nova’s 220+ automated tests, modular architecture, and thoughtful security design suggest a project built with care, even if it is early. For Windows power users and developers who value deterministic execution and safety, Nova is worth watching — and for the adventurous, worth trying today.

Frequently Asked Questions#

What makes Nova different from other Windows AI agents?#

Nova uses native Windows UI Automation (UIA) to interact with applications through their actual interface elements rather than guessing screen coordinates. This eliminates the most common source of desktop agent hallucinations. It also includes a Python code sandbox, HITL confirmation for dangerous operations, and automatic file rollback — features no competing Windows agent offers together.

Does Nova require an internet connection?#

No. Nova supports both cloud inference (Groq, OpenRouter) and local inference (Whisper.cpp for speech-to-text, llama.cpp for LLM). Users can run Nova entirely offline with local models, though cloud inference provides access to more capable LLMs.

Is Nova safe to use on a production Windows machine?#

Nova includes multiple safety layers: a Python code sandbox that blocks dangerous operations, system directory write protection, HITL confirmation for destructive actions, and automatic file rollback from backups. These features make it safer than most desktop agents, but as an early-stage project with a small community, users should exercise caution and test in a non-production environment first.

How do I install Nova on Windows?#

Clone the repository from GitHub, install Python 3.14 and the required dependencies, configure your API keys in the .env file, and run python main.py. The project requires Windows 10 or later and works with both cloud and local LLM providers.

Can Nova automate any Windows application?#

Nova can automate any application that exposes UI elements through Windows UI Automation. Most modern Windows applications (including Microsoft Office, Chrome, VS Code, and system dialogs) support UIA. Legacy applications that render custom-drawn interfaces without accessibility support may not work reliably with Nova’s UIA-based approach.
