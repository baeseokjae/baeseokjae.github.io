It sits between an agent and its tools to answer one question before every action: is this data allowed to go to this destination? Cloudflare’s Kenton Varda and Sunil Pai named it in September 2025 with a thesis that reads as obvious once you see it: LLMs are better at writing code to call MCP than at calling MCP directly.
