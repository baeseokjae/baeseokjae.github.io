WhisperX transcribe with Claude Code lets you build a fully local, privacy-first audio transcription skill that converts meetings, interviews, and podcasts into structured Markdown transcripts with speaker labels, word-level timestamps, and speaker diarization — all without sending your audio to any cloud API. By combining WhisperX’s 70x realtime transcription speed with Claude Code’s custom skill system, you get a powerful AI agent that handles everything from a single audio file to batch processing entire folders, with optional speaker recognition via pyannote.

What Is WhisperX and Why Does It Matter for Claude Code?#

WhisperX is an enhanced version of OpenAI’s Whisper speech recognition model that adds three critical capabilities: word-level timestamps via wav2vec2 forced alignment, speaker diarization through pyannote, and batched inference for dramatically faster processing. With over 23,313 GitHub stars and 2,361 forks as of July 2026, it is the most popular open-source transcription enhancement tool available. It was accepted at INTERSPEECH 2023 and won 1st place at the Ego4d transcription challenge.

For Claude Code users, WhisperX fills a major gap. Claude Code can read and write code, analyze files, and execute commands, but it cannot natively process audio. By wrapping WhisperX in a Claude Code skill (defined in a SKILL.md file), you give Claude Code the ability to transcribe any audio or video file, identify who spoke when, and produce clean, structured output that Claude can then analyze, summarize, or act upon.

The Claude Code skill ecosystem has grown rapidly — there are now over 125 transcription-related skills on GitHub as of July 2026. However, most are thin wrappers. A well-built WhisperX skill provides setup verification, model selection, batch processing, and speaker diarization in a single, reliable package.

How Does the WhisperX Pipeline Work?#

WhisperX operates in three distinct stages that together produce a far superior transcript compared to vanilla Whisper.

Stage 1: Speech-to-Text with Whisper#

The pipeline begins with OpenAI’s Whisper model, which converts audio into text. WhisperX supports all model sizes from tiny (fastest, least accurate) to large-v3 (most accurate, slower). The large-v2 model requires less than 8GB of GPU memory with beam_size=5 when using the faster-whisper backend, making it accessible on most modern GPUs including NVIDIA RTX 3060 and above.

Stage 2: Word-Level Timestamps via wav2vec2 Forced Alignment#

Vanilla Whisper produces utterance-level timestamps — it tells you when a sentence starts and ends, but not individual words. This is a well-known limitation. WhisperX solves it by running wav2vec2 forced alignment, which aligns each transcribed word to its exact position in the audio waveform. The result is word-accurate timestamps that are essential for subtitle generation, precise editing, and speaker turn analysis.

Stage 3: Speaker Diarization via pyannote#

The final stage uses pyannote’s speaker-diarization-community-1 model, which has been downloaded approximately 4.97 million times on HuggingFace with 877 likes. This model identifies “who spoke when” by analyzing voice characteristics and assigning each segment to a speaker (Speaker 0, Speaker 1, etc.). It achieves roughly 10-11% Diarization Error Rate (DER) on standard benchmarks, which is competitive with commercial cloud services.

Getting Your HuggingFace Token#

The pyannote speaker diarization model requires authentication. You need to:

  1. Create a free account at huggingface.co
  2. Accept the terms of use for pyannote/speaker-diarization-community-1
  3. Generate a User Access Token from your account settings
  4. Set it as an environment variable: export HF_TOKEN=hf_your_token_here

How Do You Create a Claude Code Skill for WhisperX Transcription?#

A Claude Code skill is defined by a SKILL.md file placed in your project directory. When Claude Code starts in that directory, it reads the skill file and gains the custom capabilities defined there. Here is the structure for a WhisperX transcription skill:

The SKILL.md File#

The skill file defines a custom slash command (e.g., /transcribe) that Claude Code can invoke. It includes:

  • Description: What the skill does and when to use it
  • Prerequisites: What must be installed before use
  • Parameters: File path, model size, language, device, and diarization toggle
  • Execution steps: The exact commands to run for transcription

A well-designed skill also includes a setup checker that verifies all dependencies (ffmpeg, whisperx, torch, HF token) before attempting transcription, saving users from cryptic error messages mid-process.

How Do You Transcribe Audio with Speaker Labels Step by Step?#

Once your Claude Code skill is set up, transcribing audio follows a straightforward workflow:

Step 1: Prepare Your Audio File#

WhisperX accepts any ffmpeg-compatible format: MP4, MOV, MP3, WAV, M4A, and more. For best results, use audio with a sample rate of 16kHz or higher. If your file is a video, WhisperX extracts the audio track automatically.

Step 2: Run the Setup Checker#

Before the first transcription, run the skill’s setup checker to verify all dependencies:

# The skill checks for:
# - ffmpeg availability
# - whisperx installation
# - PyTorch with CUDA (if GPU requested)
# - HF_TOKEN environment variable (for diarization)

This prevents wasted time on failed transcriptions due to missing dependencies.

Step 3: Execute the Transcription#

Invoke the skill with your file:

# Example: /transcribe meeting.mp4 --model large-v3 --diarize

The skill will:

  1. Convert the audio to the correct format if needed
  2. Load the Whisper model (cached after first use)
  3. Transcribe the audio with word-level timestamps
  4. Run speaker diarization to assign speaker labels
  5. Output a structured Markdown file

Step 4: Review the Output#

The transcription produces a Markdown file with speaker turns, timestamps, and optional confidence scores. Each speaker segment is clearly labeled and timestamped.

What Advanced Features Does a WhisperX Claude Code Skill Support?#

Beyond basic single-file transcription, a well-built skill offers several powerful capabilities:

Batch Processing#

Process multiple files in a single command, with model reuse across files to avoid reloading the model for each transcription:

# Transcribe all audio files in a directory
/transcribe ./recordings/ --batch

The model is loaded once and reused, making batch processing significantly faster than running individual transcriptions.

Model Selection and Progressive Fallback#

Choose the right model for each use case:

  • tiny/base: Quick drafts, low-resource machines, rough transcription
  • small/medium: Good balance for most users
  • large-v2/large-v3: Maximum accuracy for important meetings, interviews, or content creation

A progressive fallback strategy can automatically retry with a smaller model if the selected model runs out of memory.

Folder Watch Automation#

Using tools like fswatch or inotifywait, you can set up automatic transcription of any new audio file that appears in a watched folder:

# Automatically transcribe new files in ./inbox/
fswatch -o ./inbox/ | xargs -I{} /transcribe {}

This is ideal for recording pipelines, automated meeting bots, or podcast production workflows.

Interactive Speaker Renaming#

After transcription, some skills prompt you to rename detected speakers:

Detected speakers: Speaker 0, Speaker 1, Speaker 2
Who is Speaker 0? Alice
Who is Speaker 1? Bob
Who is Speaker 2? Charlie

The transcript is then updated with the real names, making it much more useful for distribution.

What Common Issues Will You Encounter and How Do You Fix Them?#

GPU Memory Errors#

Problem: CUDA out of memory when using large-v3 with default settings.

Solution: Reduce batch size, switch to float16 precision, or use a smaller model. The large-v2 model requires under 8GB GPU memory with beam_size=5 using the faster-whisper backend.

HuggingFace Token Authentication#

Problem: 401 Unauthorized when loading pyannote diarization model.

Solution: Ensure HF_TOKEN is set in your environment and that you have accepted the terms of use for pyannote/speaker-diarization-community-1 on HuggingFace.

Model Download Failures#

Problem: Transcription fails because the Whisper model cannot be downloaded.

Solution: Check your internet connection. Models are cached locally after the first download, so this only affects the first run. You can also pre-download models using whisperx --download-model large-v3.

Alignment Failures on Short Audio#

Problem: wav2vec2 forced alignment fails on very short clips (under 3 seconds).

Solution: Ensure your audio segments are at least 3-5 seconds long. For very short clips, consider disabling alignment and using Whisper’s native timestamps.

No Speakers Detected#

Problem: Diarization returns only one speaker for a multi-speaker recording.

Solution: Check audio quality. Diarization works best with clean, non-overlapping speech. Background noise, music, or heavy crosstalk can confuse the model. Try using a higher-quality audio source or preprocessing with noise reduction.

Why Should You Choose Local Transcription with Claude Code?#

Privacy and Data Sovereignty#

Every major cloud transcription service requires uploading your audio to their servers. For confidential meetings, legal depositions, medical consultations, or internal strategy discussions, this is a non-starter. WhisperX runs entirely on your machine — no audio data ever leaves your computer. This is the single strongest argument for local transcription.

Frequently Asked Questions#

Does WhisperX transcribe work with any Claude Code compatible agent?#

Yes. The SKILL.md format is supported by Claude Code, Codex CLI, Cursor, Aider, and Continue.dev. Any agent that reads AGENTS.md or SKILL.md files can use the WhisperX transcription skill. The skill defines the commands and workflow, and the agent executes them.

How accurate is WhisperX speaker diarization compared to cloud services?#

WhisperX with pyannote achieves approximately 10-11% Diarization Error Rate (DER) on standard benchmarks, which is competitive with commercial cloud services. In practice, accuracy depends heavily on audio quality — clean recordings with minimal overlap produce excellent results, while noisy environments or heavy crosstalk can reduce accuracy.

Can I transcribe YouTube videos with WhisperX and Claude Code?#

Yes, but you need to download the audio first using a tool like yt-dlp. The WhisperX skill itself processes local audio files. Once you have the MP4 or audio file downloaded, you can transcribe it with full speaker diarization support.

What is the minimum hardware requirement for WhisperX with speaker diarization?#

For GPU transcription with the large-v2 model, you need an NVIDIA GPU with at least 8GB VRAM. For CPU-only transcription, any modern multi-core processor will work, but expect 1-2x realtime speed. The tiny and base models run well on CPU and are suitable for quick drafts or low-resource environments.

How do I rename speakers after transcription?#

After the initial transcription, speakers are labeled as Speaker 0, Speaker 1, etc. Some Claude Code skills include an interactive renaming step where the agent asks you to identify each speaker. Alternatively, you can manually edit the Markdown output using find-and-replace to substitute real names for the generic labels.
