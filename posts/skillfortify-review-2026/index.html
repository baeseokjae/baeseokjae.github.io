Introduction — What Is the Agent Skill Security Crisis?#

The rapid adoption of AI agent frameworks — from Claude Code and Cursor to MCP servers and AutoGen — has created a new attack surface that traditional security tools were never designed to address. Agent skills, plugins, and tools execute with elevated privileges inside development environments, CI/CD pipelines, and production systems. The ClawHavoc campaign of January-February 2026 demonstrated the scale of the threat: over 1,200 malicious skills infiltrated the OpenClaw marketplace, compromising developers who trusted community-contributed agent extensions. In response, 12 reactive security tools emerged, but all relied on heuristic pattern matching with no formal guarantees. SkillFortify, published on arXiv (2603.00195) by Qualixar, is the first tool to apply sound static analysis — formal verification — to the problem of AI agent skill security. This review examines whether SkillFortify delivers on its promise of mathematically grounded protection.

What Is SkillFortify? — Overview and Core Architecture#

SkillFortify is a formal security scanner for AI agent skills and plugins. Unlike every other tool in the agent security space, it does not rely on regex patterns, YARA rules, or LLM-based behavioral prediction. Instead, it applies sound static analysis — a technique from programming language theory that provides mathematical guarantees about the absence of certain classes of vulnerabilities.

The tool operates entirely offline, requires no external API calls, and supports Python 3.11+. It scans skill definitions across 22 AI agent frameworks, including MCP, LangChain, CrewAI, Claude Code, Cursor, AutoGen, and others. The scanner produces an Agent Dependency Graph (ADG), a lockfile, a trust score, and an ASBOM (Agent Software Bill of Materials) in CycloneDX 1.6 format.

SkillFortify is part of the Qualixar platform, which includes 7 products and 7 peer-reviewed papers covering agent reliability. The author, Varun Pratap Bhardwaj, brings 15+ years of enterprise technology experience alongside a law degree (LL.B.) — a combination that informs both the technical rigor and the regulatory awareness embedded in the tool’s design.

The DY-Skill Attacker Model — How Does Formal Threat Modeling Work for Agent Skills?#

SkillFortify introduces the DY-Skill attacker model, an adaptation of the classic Dolev-Yao model from cryptographic protocol analysis. The Dolev-Yao model assumes the attacker controls the entire network and can intercept, modify, and replay messages — but cannot break cryptography. SkillFortify adapts this to the agent skill lifecycle with a maximality proof: the model captures every realistic attack vector an adversary could exploit across the five phases of a skill’s lifecycle.

The five phases modeled are:

  1. Discovery — How skills are found and evaluated by users
  2. Acquisition — How skills are downloaded and installed
  3. Installation — How skills are set up in the agent environment
  4. Execution — How skills run and interact with the system
  5. Update — How skills receive updates and patches

The DY-Skill model is formally proven to be maximal — meaning any attack achievable by a real-world adversary is captured within the model. This is a significant departure from heuristic approaches, which can only detect attack patterns they have seen before. Formal modeling means SkillFortify can detect novel attack vectors that no human analyst has yet documented.

Sound Static Analysis — How Does Formal Verification Work in Practice?#

Sound static analysis is the core technical innovation behind SkillFortify. In static analysis, “soundness” means that if the analysis says a vulnerability does not exist, it mathematically cannot exist. This is the opposite of heuristic scanning, which can only say “I didn’t find a match for the patterns I know.”

Key Features Deep Dive#

22 Framework Support and Auto-Discovery — Which Frameworks Are Covered?#

SkillFortify supports 22 AI agent frameworks — the broadest coverage of any agent security scanner on the market. Competitors typically cover 1 to 5 frameworks. The tool includes auto-discovery: point it at a project directory, and it automatically detects which frameworks are in use and applies the appropriate analysis rules.

Supported frameworks include MCP (Model Context Protocol), LangChain, CrewAI, Claude Code, Cursor, AutoGen, OpenAI GPTs, Anthropic Agent Skills, OpenClaw, and 14 others. This breadth is a significant moat — organizations using multiple agent frameworks can standardize on a single security tool.

Agent Dependency Graph and Lockfile Generation — How Does Dependency Resolution Work?#

SkillFortify builds an Agent Dependency Graph (ADG) that maps every skill, its dependencies, and the transitive relationships between them. Dependency resolution uses a SAT-based solver that handles 1,000-node graphs in under 100 milliseconds. The lockfile pins exact versions of every skill and dependency, enabling reproducible builds and preventing dependency confusion attacks.

This is particularly important for the agent ecosystem, where skills can pull in other skills as dependencies — creating a supply chain that mirrors the npm/PyPI ecosystem but with far less security tooling. The ADG makes the entire dependency tree visible and auditable.

Trust Score Algebra and Graduated Trust Levels — How Are Skills Rated?#

SkillFortify computes a trust score for each skill using a formal algebra with proven monotonicity. The trust score aggregates multiple signals:

  • Static analysis results (vulnerabilities found or not found)
  • Dependency quality (are dependencies themselves trusted?)
  • Source reputation (is the skill from a verified publisher?)
  • Update frequency and consistency
  • Code complexity and obfuscation indicators

The monotonicity property means that adding more evidence never decreases the trust score — a formal guarantee that the scoring system behaves rationally. Skills are assigned graduated trust levels that inform deployment decisions: untrusted skills can be sandboxed, while fully trusted skills can run with normal privileges.

ASBOM Generation for Compliance — What Is an Agent Bill of Materials?#

SkillFortify generates an ASBOM (Agent Software Bill of Materials) in CycloneDX 1.6 format. This is a machine-readable inventory of every skill, dependency, and their security properties. For enterprises subject to regulatory compliance (SOC 2, ISO 27001, FedRAMP), the ASBOM provides auditable evidence of supply chain security for AI agent deployments.

The ASBOM includes vulnerability identifiers, trust scores, dependency relationships, and framework metadata. It can be fed into existing SBOM management tools and compliance dashboards.

CI/CD Integration and HTML Dashboard — How Does It Fit Into Development Workflows?#

SkillFortify integrates into CI/CD pipelines as a CLI tool that returns structured JSON output. It also generates an HTML dashboard with visual summaries of scan results, dependency graphs, and trust score distributions. The dashboard is self-contained and requires no server infrastructure — it can be served from static storage or attached to CI/CD artifacts.

The 100% precision and 0% false positive rate are the standout numbers. In enterprise security operations, false positives are the primary source of alert fatigue — security teams learn to ignore tools that cry wolf. SkillFortify’s formal approach means every alert is a real vulnerability, and every clean scan is a genuine clean bill of health.

The 94.1% recall means the tool misses approximately 5.9% of vulnerabilities. This is bounded by the DY-Skill model — vulnerabilities outside the model’s scope are not detected. However, the model is proven maximal for the five-phase skill lifecycle, so the recall gap represents attack vectors that fall outside the modeled threat landscape.

SkillFortifyBench — The 540-Skill Evaluation Framework#

SkillFortifyBench is the evaluation dataset used to measure SkillFortify’s performance. It contains 540 skills across three formats (MCP, Claude Code, and OpenClaw), split evenly between 270 malicious skills (covering 13 attack types) and 270 benign skills (covering 5 categories).

The 13 attack types in the malicious set include prompt injection, tool poisoning, dependency confusion, credential theft, command injection, data exfiltration, privilege escalation, backdoor installation, supply chain substitution, manifest tampering, update hijacking, logic bomb, and time-of-check-time-of-use (TOCTOU) attacks.

The 5 benign categories cover utility tools, data processing, API wrappers, monitoring, and development helpers. This balanced design ensures the benchmark tests both detection capability and false positive resistance.

Why Formal Verification Matters More Than Pattern Matching#

The fundamental difference is mathematical. Heuristic scanners can only detect vulnerabilities they have seen before and encoded as patterns. A novel attack — one that doesn’t match any existing rule — passes through undetected. Formal verification, by contrast, models the entire attack surface and can detect any attack that falls within the model’s scope, regardless of whether it has been seen before.

This is not a theoretical distinction. The ClawHavoc campaign used novel techniques that evaded all 12 heuristic scanners available at the time. A formal verification tool like SkillFortify, with its DY-Skill model covering the full skill lifecycle, would have detected those attacks because they fell within the modeled threat landscape.

The ELv2 is not OSI-approved as an open source license, which has implications for enterprise procurement. Some organizations require OSI-approved licenses for their software supply chain. However, for internal security tooling, the ELv2 is generally acceptable — the restrictions primarily target cloud service providers who might offer SkillFortify as a hosted service.

The tool is free to use. There is no paid tier or enterprise license announced as of July 2026. The Qualixar platform may introduce commercial licensing in the future, but current access is unrestricted for all use cases permitted by the ELv2.

Real-World Use Cases#

Enterprise Governance for Claude Code and Cursor Deployments#

Organizations deploying Claude Code or Cursor across development teams need to ensure that agent skills don’t introduce supply chain vulnerabilities. SkillFortify can be integrated into the onboarding pipeline: every skill added to the team’s shared repository is scanned before it becomes available. The trust score and ASBOM provide auditable evidence for security reviews.

CI/CD Pipeline Security for Agentic Development#

In CI/CD pipelines, agent skills can execute with significant privileges — reading secrets, modifying code, and deploying artifacts. SkillFortify scans skills at build time, failing the pipeline if a skill fails the security check. The lockfile ensures that the exact same skill versions are used in production as were scanned in CI.

Air-Gapped Environments and Offline-First Architecture#

For defense, government, and financial sector deployments, air-gapped environments are common. SkillFortify’s offline-first architecture — no external API calls, no telemetry, no cloud dependency — makes it suitable for these environments. The tool can be installed via a single PyPI package and run entirely on isolated infrastructure.

Limitations and Considerations#

Early Stage — 26 GitHub Stars, Single Author#

SkillFortify has 26 GitHub stars and 5 open issues as of July 2026. The project is effectively a single-author tool. While the academic rigor is impressive, the community and ecosystem around the tool are minimal. Enterprise buyers should evaluate the bus factor and long-term maintenance prospects.

Elastic License vs Open Source#

The Elastic License 2.0 is source-available but not OSI-approved open source. Organizations with strict open source policies may need legal review before adoption. The license also creates uncertainty about future pricing — if Qualixar introduces a paid tier, users of the free version may face feature limitations.

Python 3.11+ Requirement#

SkillFortify requires Python 3.11 or later. Organizations still running Python 3.9 or 3.10 — which are still common in enterprise environments — will need to upgrade before adoption. This may be a non-trivial migration for teams with legacy infrastructure.

No Real-World Enterprise Case Studies Yet#

The benchmark results are strong, but they are based on a synthetic benchmark (SkillFortifyBench) created by the same author. Independent third-party validation and real-world enterprise case studies are not yet available. The 0% false positive rate, while mathematically grounded, has not been validated in diverse production environments.

The Qualixar Ecosystem — Part of a Broader Reliability Platform#

SkillFortify is one of 7 products in the Qualixar platform, which collectively address agent reliability across the full lifecycle. The Qualixar portfolio includes tools for agent testing, monitoring, observability, compliance, and security — all backed by peer-reviewed research. This ecosystem positioning is important: SkillFortify is not a standalone scanner but a component of a broader reliability infrastructure for AI agents.

The Qualixar platform has produced 7 peer-reviewed papers covering agent reliability topics. This academic foundation differentiates Qualixar from the typical open source security tool that relies on community contributions and ad-hoc methodology.

Conclusion — Is SkillFortify Ready for Enterprise?#

SkillFortify represents a genuine breakthrough in AI agent security. It is the first tool to apply formal verification — sound static analysis with mathematical guarantees — to the problem of agent skill security. The benchmark results (96.95% F1, 100% precision, 0% false positive rate) are the strongest in the space, and the DY-Skill attacker model provides a formally grounded threat model that heuristic scanners cannot match.

For organizations already deploying AI agent frameworks at scale — particularly Claude Code, Cursor, MCP, or AutoGen — SkillFortify is worth evaluating today. The offline-first architecture, ASBOM generation, and CI/CD integration make it practical for real-world deployment. The zero false positive rate alone justifies the evaluation: if it performs as advertised, it eliminates the single biggest operational pain point in security scanning.

However, the tool is early stage. A single author, 26 GitHub stars, no independent validation, and an Elastic License 2.0 that may raise procurement concerns are real considerations. Enterprise buyers should run their own evaluation on their own skill repositories before committing.

The bottom line: SkillFortify is the most technically sophisticated agent security scanner available, and its formal verification approach is the right direction for the industry. It is not yet a mature enterprise product, but it is the tool that every organization using AI agents should be watching — and probably testing.
