Companion material for the October 20, 2026 editorial corrections, batch two.

The CSV files are proposed evaluation worksheets. Empty results are intentional:
they are not completed product trials. Fill them with your own observed evidence.
The context packet is a planning template.

evidence_checks.py contains deterministic synthetic examples and arithmetic.
Run: python3 -B verify_examples.py
The command prints a report and makes no network or model calls.
offline-results.json records the editorial execution and exact source hashes.
Only --write-run deliberately replaces that record.

comfy-api-prompt.json is an illustrative API-prompt graph, not UI workflow JSON.
Replace the checkpoint placeholder with a compatible installed model. The offline
checker validates references only. No GPU generation or ComfyUI execution is
claimed. Invoice checks do not establish image-reading accuracy. Quest checks do
not implement an atomic inventory transaction. No OAuth server is implemented.

No live vendor benchmarks, paid API calls, third-party attacks, real credentials
or private customer data are included.
