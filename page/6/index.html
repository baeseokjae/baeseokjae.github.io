What Is Agentry? A Framework That Treats AI Agents as React Components Agentry is an open-source TypeScript framework that reimagines AI agents as React components. Instead of writing imperative agent logic with chained API calls and manual state management, you define agents declaratively using JSX — the same syntax React developers use for UI components. An agent becomes a tree of <Agent>, <System>, <Tools>, and <Message> elements rendered by a custom React reconciler. Created as a Thanksgiving 2025 weekend project by Colin Dsouza, Agentry is at version 0.1.0 with 8 GitHub stars and roughly 20 monthly npm downloads.
