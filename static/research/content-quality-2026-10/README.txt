RockB article companion material, October 2026

Python files are original teaching examples requiring Python 3.10 or later.
Download all four .py files into one directory. Run:
  python3 verify_examples.py
This performs only offline deterministic and mocked checks.

responses_example.py has an optional live entry point. It requires the OpenAI
Python package, OPENAI_API_KEY, and OPENAI_MODEL; live usage incurs API charges
and enables provider-side response storage. Use synthetic data.

The CSV evaluation worksheets contain proposed cases with status "not run".
They are not reports of live vendor tests.
Cost inputs are hypothetical USD assumptions, not current price quotations.
The archive inventory contains metadata only; it is not an attack corpus.
The SonarQube config was parsed and checked against documentation, not tested
against an authenticated server. Never put a real token in a shared file.
