An agent becomes a tree of <Agent>, <System>, <Tools>, and <Message> elements rendered by a custom React reconciler. Created as a Thanksgiving 2025 weekend project by Colin Dsouza, Agentry is at version 0.1.0 with 8 GitHub stars and roughly 20 monthly npm downloads.
